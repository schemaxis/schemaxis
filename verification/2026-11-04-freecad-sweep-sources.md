# Sweep history assembly handoff repair

Scope: closed saved-source admission for native AdditivePipe/SubtractivePipe,
centroid Point-engine correspondence, and floating-point serialization of copied
placements, attachment offsets and derived Pad/Pocket sketch normals.

The public FreeCAD 1.1.4 property contract was checked against original saved
flanged-elbow controls. Their complete property, transient and extension sets are
finite installed policy; authored input cannot expand them. Unknown fields and
Python properties remain refused before native source opening.

Copying resolves the centroid attacher selector from automatic zero to Point
index three. Plane index one is refused for that source. Native matrix/quaternion
conversion and recomputation introduce binary64 rounding in placements and their
derived normals. The comparison binds all serialized numeric fields to a 64-ULP
budget with a unit-scale floor, including redundant angle/axis values, and keeps
all wrapper attributes and membership exact. Current assembly payloads still
require the independent fresh-regeneration oracle. This does not loosen geometry
or toolpath tolerances, or permit an authored custom direction to escape checks.

Host validation: the saved-source regression suite passed 44 tests after updating
its runner mocks to the adaptor-owned isolated launcher. Separate fixture controls
admit the original Pipe history and reject foreign/missing properties, wrong
centroid engine, material placement changes, property-type changes and axis
changes. The first host fixture probe failed on a fixture object-name assumption;
that failure is retained privately and corrected without changing the fixture.

Native development check: FreeCAD 1.1.4 successfully embedded one flanged elbow
with additive/subtractive sweeps, centroid flanges and holes into two shared
assembly instances, solved a fixed joint, reopened and independently regenerated
its saved payloads. Earlier checks exposed the Point-engine and roundoff defects;
those failures are retained. This check reused an unchanged previously generated
producer. It is a composition smoke check, not final source-bound family or
whole-adaptor qualification. Parameter edits, variant assemblies, hostile saved
state, workflow lifecycle and final integrated checks remain required.

No route, declaration, schema or authored field was added. Existing conceptual
guidance and Studio authoring remain applicable; the assembly guide describes the
newly admitted handoff and its numerical limits. Wider FreeCAD completion and
release readiness remain open.

Follow-up persistence hardening: the shared generation-two regeneration oracle now
binds the complete canonical StringHasher inventory, including strings not used by
a map or XML shadow. Allocation IDs may differ under the complete object-name
bijection; unknown flags, cycles, dangling references and duplicate semantic
records fail closed. Eleven persistence tests passed, including an unused-entry
control and owner-ID renaming. Fresh native regeneration accepted the unchanged
swept assembly; an added unused SID with refreshed artifact digests was refused
specifically for complete-string-inventory mismatch. Full caller verification
passed again after restoring the original bytes. This closes a saved-payload
admission gap; it does not qualify the complete upstream application.

Saved archive decoding now uses the existing strict member reader, including
local/central header agreement and refusal of encryption or unsupported methods.
These refusals become structured source faults before native opening. The updated
saved-source suite passed 47 tests, including inert encrypted-header and
unsupported-method mutations. No executable or encrypted payload was generated.

The independent CAM tool-template audit found a valid native null child map.
FreeCAD 1.1.4 ElementMap.cpp explicitly serializes zero for an absent child map
and restores a null pointer. Canonical comparison now records that absence as
`None`, distinct from any preceding map, while preserving child range, tag,
postfix and SID checks. Twelve persistence tests pass, including owner renaming
and rejection of invalid indices, empty ranges and foreign ownership.

The subsequent frozen integration passed the full Python suite (5,271 tests,
373 skipped) and Studio suite (815 passed, three skipped). Skips are not native
acceptance. The swept-source assembly qualifier then passed both materially
different projects: literal analytic volumes and centres, shared instances,
fixed-joint frames, two native edits and fresh reopens per project, three
refreshed-digest semantic attacks per project and verified workflow reuse.
The final source digest matched the start of the run.

Two earlier qualification failures remain failures. One completed behavioural
checks but detected shared Help generation changing its source digest. Another
failed bare workflow verification because the tool scoped its explicit runtime
only to production. The tool now carries the caller's trusted FreeCAD location
through production and all subsequent verification; the passing rerun explicitly
unset the local configuration environment. These repairs do not weaken the
native or source-freshness guards. Whole-FreeCAD and release acceptance remain
open.
