## Verification scope and independent expectations

`PYTHONPATH=src python3 -m unittest discover -s tests/unit -p test_gdal.py -v`
passes seven tests. `schemaxis adaptor conform schemaxis.gdal/1` passes host
conformance. `tools/qualify_gdal.py --gdal ISOLATED_PYTHON --output-directory FRESH`
passes full native acceptance through ordinary registry/bindings/run/verify paths.
Bulk results are retained under `evidence/programme-20261017/gdal-native1`.

Literal Int16 crop pixels are `[21,-9999,23,24,31,32,33,34,41,42,43,-9999]`, mean
32.4 after excluding nodata. The non-integer 4×3→3×2 nearest variant contains
`[21,23,24,41,43,-9999]`, mean 30.4. Outer corners remain
`[[500010,5499980],[500050,5499920]]`. The big-endian Float32 geographic fixture
checks x-longitude/y-latitude, negative y spacing and first/last rows and columns
through 6×5→9×7 resizing. All-nodata runs for UInt16, Int16 and Float32 produce
zero valid count and null minimum/maximum/mean. Additional native cases preserve
dimensionless UInt16 values including sentinel 65535 and 4096 non-round Float32
values across multiple output TIFF strips.

Nine tampering probes each run against baseline and dimensionless evidence,
refreshing outer hashes: altered pixel, affine origin, native units, boolean band,
boolean pixel, rebound source, changed trusted worker, extra publication and
extra metadata sidecar. The dimensionless output begins with literal zero;
substituting `False` would bypass ordinary Python equality but is refused by
exact numeric-type validation. Thirteen input probes cover compression, extra
bands, offsets/counts, pixel budget, truncation, extra metadata, NaN,
unresolvable affine geometry, CRS/units/nodata conflicts and outside windows.

A two-step crop→nearest workflow verifies the GeoTIFF handoff, unchanged reuse,
and invalidation after changed source bytes at the same path. Two composition
states vary output columns. Native timeout, prelaunch cancellation and cancellation return the expected structured faults. The original early
cancellation probe was conservatively treated as prelaunch timing. A revised
262144-pixel fixture observes the real native PID and consumed-input marker,
then explicitly SIGSTOPs that owned process to avoid the fast-job/polling race.
Normal dispatcher cancellation returns RUNNER_CANCELLED, kills it with exit -9,
reaps it and leaves no success receipt. This is a labelled paused-native
cancellation test, not a claim that an unmodified long-running workload was
interrupted. Its watcher is bounded and cleanup kills/reaps even on fixture
assertion failures. A separate natural race completed before termination but
correctly refused publication; it is not claimed as a killed process. Workflow verification still
requires the original source path; standalone verification uses its captured
source. This distinction is documented in the guide.

## Review fixes and qualification limits

Source/output spacing must be at least 1024 double-precision ULPs at its axis
origin and far edge. Affine verification permits four ULPs per coefficient,
well below a pixel, and never scales tolerance with coordinate magnitude. Host
probes reject unresolvable huge-origin/tiny-spacing geometry and a 0.01 coordinate
shift at origin 1e12 that the former relative tolerance could have accepted.
Native snapshots enforce closed shape, finite numeric types, integer band/EPSG/
dimensions and exact dtype-appropriate pixels. TIFF tag kind/count checks reject
floating-point strip offsets before byte indexing.

A material native finding was that Translate omitted band unit `m` in this path.
The worker now calls SetUnitType with the source read-back unit; independent TIFF
parsing and fresh native reopening both verify retention. Source metadata
assertions never overwrite conflicts. Isolated PROJ/GDAL data paths are resolved
inside the native process from its prefix; no PATH/system installation changed.

Qualified scope remains exact GDAL 3.13.3, finite Float32/UInt16/Int16,
EPSG:4326/3857, PixelIsArea north-up, single-band uncompressed strips. No arbitrary
reprojection, bilinear interpolation, compressed/tiled/BigTIFF/extra-band/mask/
overview support, semantic metadata loss or geodesic conservation claim. Nearest
sampling deliberately drops unsampled pixels. TIFF byte order, strip layout and
descriptive CRS citations may change; pixels and semantic metadata are verified.
