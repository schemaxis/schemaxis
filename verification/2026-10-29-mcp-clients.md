To repeat with an environment containing these optional SDKs:


The corresponding public APIs inspected in the installed packages were:

```python
from mcp import Client, StdioServerParameters
async with Client(StdioServerParameters(**params), mode="auto") as client:
    page = await client.list_tools()
    result = await client.call_tool("capabilities_search", {"query": "root"})

from agents.mcp import MCPServerStdio
async with MCPServerStdio(params=params) as server:
    tools = await server.list_tools()

```
