# Blender reusable typed node-group acceptance

This continuation adds reusable interfaces and nested composition across shader,
geometry and compositor domains. It is part of an unfinished whole-application
programme; the strategic capability map keeps remaining application families.

Fresh Blender 5.2.3 LTS acceptance covers a rendered shader/geometry/compositor
project, all 29 admitted domain/type mappings with saved interface readback,
named resource handles, nested geometry and a native parameter edit adopted as
a fresh packed-asset input. Literal bounds prove two nested transformations:
2.5-unit outer input produces a 5-unit lift; editing it to four produces eight.
A separate exposure change checks the compositor group's actual output pixels.

Twelve refreshed-hash native mutations are rejected in both authored and reused
projects: interface defaults, numeric bounds, an unused interface object pointer with
instance fallbacks held unchanged, a linked-but-unused nested socket
fallback, nested node muting and instance-to-group binding. Current saved bytes
are reopened in a trusted fresh runtime. Native interface and graph observations
are judged against the authored semantic definitions, and imported asset fidelity
records complete used group dependencies, including interface resource pointers.

Admission rejects recursive groups, domain crossings, unknown sockets, mismatched
literal types, unresolved resources, unbounded topology-count links and excessive
recursive geometry expansion. The same descriptor functions drive dynamic
instance validation, native constructors, assignment and persisted readback.
Standalone and normalized documents both match the public schema; semantic
checks additionally resolve user-defined interface names and resource IDs.

Limits: node catalogues remain curated. Custom interface policies/panels,
dynamic menu/bundle/closure sockets, font/sound resources and matrix literal
construction remain open. Matrix interfaces carry links without literal defaults.
Geometry collection handles work in authored native productions; portable
collection ownership and native collection-instance reuse remain explicit
unsupported dependencies during asset import. Unused library groups and native
asset-browser management remain separate open workflows.

Reproduce with `tools/qualify_blender_node_groups.py` and
`tools/qualify_blender_node_group_tamper.py`, using an explicitly selected trusted
runtime. Private retained records identify frozen source revisions and distinguish
these fresh checks from earlier production and motion milestones.

Independent integration verification repeated all five native cases, including
rotated geometry, compositor pixel changes, the 29 admitted domain/type mappings
and reuse of a natively edited nested group. Shared workflow guidance was
separately repaired to follow route identities when new routes shift the schema's
choice order; the integrated broad Studio unit suite subsequently passed.

A follow-up audit reran all twelve attacks against the current collection-capable
provider, with two unchanged native open/save controls. The same complete
current-byte native verifier accepts the controls and rejects attacks through
explicit fresh native readback guards. Companion metadata hash failures do not
count as proof of node/interface guards. The reusable trusted harness records
fault messages and observations and leaves product verification unchanged.
