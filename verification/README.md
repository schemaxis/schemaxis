# Verification records

Each file here is a compact, dated summary of a host or native qualification run:
the commands, runtime versions, checked cases and stated limits. A record describes
what was checked at that time; it is not a claim about later source revisions or
other installations.

Links into `../evidence/...` point to the bulk results of those runs. That
directory is git-ignored, and its bulk evidence is retained privately, so those
links do not resolve in a public clone. Workstation-specific locations in older
records are shown as placeholders such as `<checkout>`, `<paraview>` or
`<workstation>`.
