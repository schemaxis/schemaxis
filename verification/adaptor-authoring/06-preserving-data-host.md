# Preserving public Live Data ownership

Copyright (C) 2026 David L. F. Gaden.

This bounded shared support is accepted after independent adversarial review,
repair recheck and coordinator inspection. It connects the ordinary resident
transition to the public Live Data host and a closed private worker protocol.
Complete extractBlock authoring remains partial: compound publication, browser
behaviour and the remaining shared prerequisites are still required.

## Delivered contract

Existing workers use native-free preparation followed by an independently checked
preserving transition. The exact process nonce, monotonic generation, plan,
roots, concrete visit, candidate and protected nodes are bound together. A
completed or reversed mutation advances the generation; returning to an identical
plan cannot revive an old token. Request and reply tokens use closed fields and
exact finite JSON types. Initial acquisition validates its new owner before host
installation. A mismatched acknowledgement retains the actual client as uncertain
and leaves the prior host owner intact.

Compatible old windows can read currently measured nodes while unrelated newer
branches remain resident. The host retains each handle's original measurement
provenance and the existing checked-view exclusions. Read-only measurement does
not execute an owned plan, update a source or run unrelated `onVisit` commands.
New work protects unchanged sources and retained branches; incompatible preservation
refuses before mutation. Pending witnessed Name alignment uses a non-owning planning
projection to check ordinary eligibility and both future request envelopes first.
The predicted owner is independently checked by the host; execution still rechecks
its actual owner and candidate. A later native failure during eligible ordinary
work is reversed or reported uncertain in the already acknowledged namespace.
Names or similar settings alone never grant reuse.

A checked refusal keeps a healthy owner. Verified reversal preserves its previous
host evidence and adopts only the verified next generation. Uncertainty retains
the client and blocks implicit reuse. Lost preserving replies quarantine the
single request slot until explicit release; no blind resend, replacement reader
or status overwrite occurs. Selected inspection uses retained transport and exact
owner readback too. Its complete owner-bearing reply admits required measurements
and degrades optional geometry to `geometryUnavailable` when needed. Oversized
required metadata still refuses. Oversized fault envelopes retain critical ownership outcomes.
Initial legacy loading, cancellation and explicit close retain their documented
cleanup behavior. Supplied factories must explicitly support retained requests.

## Host evidence

The repaired affected combined set passed **244 tests, 10 skipped**, in 398.433
seconds, including all **35 preservation tests** and the shared pipeline and Graph
transition regressions. This is not the final full host suite. Skips require
optional native applications or configuration.

Checks exercise real public services and counted workers: old/new windows,
ordinary siblings/options, witnessed identity views, unrelated commands,
preparation refusal, unknown construction, measured-reply budget failure,
verified and failed reversal, exact generations and malformed acknowledgement or
request tokens. Complete state snapshots prove that rejected new work in another
witnessed namespace does not relabel, advance ownership or change cached evidence.
Spies reject every backend, registry or closure-lifecycle call during projected
preparation. Tests also cover wrong predicted owners/preparation digests, changed
concrete sweep visits, interleaving and corrupt rollback status.

Actual file-IPC tests check inspection boundaries with the owner included: the
exact and near-boundary replies retain measurements with `geometryUnavailable`;
adequate space retains geometry; oversized required metadata refuses. Bounded
error envelopes preserve uncertainty. Nine inventory reconciliation/path checks
passed; Help and inventory were current. Independent repair recheck and coordinator inspection accepted this bounded support.

request after accepting the Name performs a pending alignment followed by new
derived work, before any inspection or Refresh can align it.
