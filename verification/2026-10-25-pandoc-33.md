# Pandoc transcript block for whisper.cpp segments — 25 October 2026

Scope: the existing closed `schemaxis.pandoc/1` report route gains one content block,
`transcript`, that publishes a retained whisper.cpp `segments.json` as a provenance
paragraph and a `Start (ms)` / `End (ms)` / `Text` table in standalone HTML5 and
editable DOCX. A shared, dependency-free `schemaxis.core.timed_text` module defines the
closed machine-draft contract. No new native mapping: the block expands to the
existing `Para` and `Table` AST and the same sandboxed writers. Earlier reviews:
[route completion](2026-10-17-pandoc-completion.md),
[hostile evidence](2026-10-24-pandoc-evidence.md),
[transcript](2026-10-24-pandoc-transcript.md),
[closeout](2026-10-24-pandoc-closeout.md) and
[image width](2026-10-24-pandoc-allocation.md).

## Gap and decision

Before this change `acceptedArtifacts` was empty, so a verified whisper.cpp
`segments.json` (a `text` artifact) could not feed a report; the only route was a
hand-typed literal table with no binding to the transcription receipt.

- The route accepts the `text` artifact kind. The handoff check is by kind and
  route, not by field, so a text artifact reference at another string field of a
  report would be written as that field's path text. Use it only at `segments.path`.
- `{"kind":"transcript","segments":{"path":…,"sha256":…}}`: absolute `.json` path,
  optional lowercase SHA-256 pin. Planning checks shape only and reads no file.
- The run reads the file once (no links, regular file, at most 4 MiB), checks the
  pin, parses strict UTF-8 JSON and validates the closed contract: exactly the
  `schemaxis.whispercpp.segments/1` members at every level plus the producer's optional
  closed `segmentation` member; ordered, non-overlapping integral-millisecond cues
  inside the recorded audio duration; nonblank plain cue text. Budgets: 512 cues,
  256 characters per cue, 32768 characters per document, 2 transcripts per report,
  inside the existing 128 authored blocks and 65536 characters; each transcript expands to a paragraph and a table for the writer.
- Any other `version`, an extra or missing member, or a review status other than the
  uncertified machine draft is refused (`TIMED_TEXT_*`); a human-review status
  is never read, written or certified here and needs its own versioned contract.
- The captured bytes are retained as `transcript-<section>-<block>.json`; their
  SHA-256, size and counts are bound in `captures.json`. Verification re-validates
  them, rebuilds paragraph, table and trusted AST, and compares HTML, DOCX and fresh
  Pandoc readback.
- Reports without a transcript block plan and verify exactly as before.

## Limits

- Only the closed machine-draft document is read; recognition accuracy, speakers, word
  times and caption cue formats are not published or certified, and a human review
  status is not supported.
- The contract binds to `schemaxis.whispercpp.segments/1` as produced by whisper.cpp
  1.9.5; a producer change needs a reviewed update to `timed_text.py`.
- A cue with a doubled space, non-breaking space or unsupported formatting character is
  refused with its location, not altered; long recordings need splitting past 512 cues.
- The text artifact kind is route-wide, so it cannot be restricted to `segments.path` by the
  route alone (see above).
- Layout, accessibility, PDF and Word application behaviour are not exercised.
