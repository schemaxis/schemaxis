# Tesseract scanned-page OCR completion (allocation 63)

Scope: new route `schemaxis.tesseract/1`, operation `recognizePage`. This note records
what was built and run, with scope limits; it proves that evidence exists, not that its
conclusions are true. Bulk transcripts are private evidence, not committed.

## Delivered

Adaptor package `src/schemaxis/adaptors/tesseract` (manifest, `adaptor.py`, strict
`tsv.py`, capabilities, search cases, guidance, readiness, Studio starters, upstream),
`docs/tesseract.md`, nine examples plus two workflows, fixtures under
`examples/schemaxis/fixtures/tesseract`, host tests `test_tesseract.py` and
`test_tesseract_native_boundary.py`, `tools/qualify_tesseract.py` and fixture tools.

## Runtime and model

Tesseract 5.5.3 (Leptonica 1.87.0, libpng 1.6.59) privately built; English fast model
`eng.traineddata`, SHA-256 `7d4322bd2a7749724879683fc3912cb542f19906c83bcc1a52132556427170b2`
(tessdata_fast commit 87416418657359cb625c412a48b6e1d6d41c29bd). Native text and TSV
output is requested with `-c tessedit_create_txt=1 -c tessedit_create_tsv=1`; no
configuration files or global tessdata are used.

## Host tests

`PYTHONPATH=src python3 -m unittest tests.unit.test_tesseract tests.unit.test_tesseract_native_boundary`
passed (22 tests), including a fake native executable, the strict TSV reader's
structural refusals (header, page record, numbering, containment, confidence, text,
limits), forged and refreshed-digest tampering, offline verification with the
executable deleted, timeout process-tree termination and pre-launch cancellation.

## Native qualification

Run with Tesseract 5.5.3 and the pinned model; bounded and serial. Independent
expectations: committed fixtures draw literal words, and ink boxes were measured from
the PNG pixels (allowed error 3 px horizontally and 5 px vertically; the qualifier
reports the maximum observed error for each run). Cases: two-line baseline, changed word pair,
single-line segmentation; controls: single-line on a two-line page and a blank page
(both `OCR_NO_TEXT`), 300 dpi override, alpha and interlaced PNG refusal, wrong model
pin, missing source/model/runtime, wrong-pixel origin (`ORIGIN_MISMATCH`), timeout,
cancellation. A second native pass was identical (repeatability, not truth). Offline
verification launched no process. Seventeen hostile mutations were each refused (asserted only as
`VERIFICATION_FAILED`) and restored; ten of them (forged box, confidence, word and text,
and five native-file edits) had the receipt digests refreshed so that only the content
checks could catch them, and seven (stale source or model, forged runtime claim,
executable or filename, extra file, missing output) did not. Workflow reuse and same-path invalidation passed. A real verified Gnuplot
chart PNG fed OCR through `$artifact`; the authored title words were recognized and
located by pixel measurement.

Shared native conformance (`adaptor conform --native`, run by the qualifier with
`--conform`) produced a verified native receipt for the two named cases with timeout
and cancellation probes; it was **not recorded** (`adaptor record` was not run), so the
route is not registered as native-qualified. Host conformance, readiness admission,
guidance, reference/help `--check`, the Studio search acceptance test and the
adaptor architecture/readiness/catalogue suites passed. Registering this adaptor
shifts the workflow adaptor's indexed route guidance, so
`src/schemaxis/adaptors/workflow/guidance.json` was re-indexed (a tesseract record
added at its position) and generated references and packaged Help were regenerated.

## Limits and unresolved

* A MuPDF 1.28.5 page handoff was **not run**: only MuPDF 1.27.0 is installed and the
  MuPDF adaptor correctly refuses it. The example and `scanned.pdf` fixture exist; the
  qualifier runs the handoff when `--mupdf` supplies a qualified runtime. Origin binding
  was exercised natively only with hand-built summaries, not MuPDF output.
* The OCR pixel budget (4,194,304 pixels) is smaller than MuPDF's render limit, so a
  full Letter or A4 page at 300 dpi is refused as `IMAGE_RESOURCE_LIMIT`; about 200 dpi
  is the most a full Letter page can use. Declared `dpi` does not change this.
* Nothing verifies that the pinned model is actually English; the SHA-256 pin identifies
  the bytes only.
* Page segmentation is not layout analysis: a mismatched choice can return no words
  (observed on the qualification fixture only) or wrong text.
* Machine confidence is uncalibrated; no accuracy, identity, accessibility, universal
  font, language, layout, handwriting, multipage, medical or security claim.
* Pandoc OCR-block ingestion is not supported; a separate handoff design is future work.
* No receipt was recorded; admission/readiness and conformance results are in the
  private evidence.
