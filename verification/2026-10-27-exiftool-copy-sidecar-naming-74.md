# ExifTool copy, sidecar and naming workflows, objective E4: verification note

Status: **E4 implemented in an isolated source for this note's scope; focused host, native, lifecycle, workflow and mutant checks were run; independent family review, the
adoption of the root's reviewed E3 patch and the global union gates (all native qualifiers, the full host suite, shared fixtures, privacy and package checks) are separate and are not
claimed here.** This note covers `copyMetadata`, `applySidecar`, `exportSidecar`, `planNames` and `organiseCopies` on route `schemaxis.exiftool/1`. No upstream registration or
qualification label is changed by this work, and nothing here certifies photograph provenance, capture time, location, authorship or privacy.

## Reproduce

Host (no native process unless `SCHEMAXIS_EXIFTOOL` names an absolute ExifTool 13.55 script, which also enables the native classes):

- `PYTHONPATH=src python3 -B -m unittest tests.unit.test_exiftool_e4_naming tests.unit.test_exiftool_e4_surface tests.unit.test_exiftool_e4_qualifier_rows` and the other `tests.unit.test_exiftool_e4_*` modules.

## Limits

- Every expected value is a literal derived by hand; ExifTool output is never the oracle for a value it wrote. Mutant cases are synthetic edits of retained records and are distinguished from real native observations in the qualifier report.
- Selected typed values only: no full-block, MakerNote or unknown-tag transfer, no XMP structures, no merge or edit of an existing sidecar.
- `copyMetadata` and `applySidecar` carry the capture time and location groups through the E3 time and location planners (an internal absolute captured-time set, also into a destination that records no capture time; rounded coordinates), each item with the independent source-to-output proof T, alone or in any union with the other groups in one write with one proof set; `exportSidecar` writes both. A destination without an Exif block or ExifIFD is refused, never created.
- ExifTool 13.55 lists the sidecar altitude reference literally but its Composite altitude inverts the sign for code 2; every such sidecar carries that residual.
- The route accepts image and text artifacts, so a per-binding artifact kind (`TYPE_MISMATCH` at bind time) is not available; a wrongly bound plan or photo is refused by its consumer.
- An EXIF-only camera, lens or serial text with an edge space is refused because native 13.55 itself lists an EXIF ASCII value trimmed (an existing anchoring limit of the reader, not a transfer normalisation). A captured time set into a destination that records none uses one carrier (an existing ExifIFD, otherwise XMP) and says so as a declared loss.
- The native listing comparison (T-native) of a captured time composes one time from every carrier each listing states, independently for the local time, the offset and the fraction: ExifIFD `DateTimeOriginal` with its offset and sub-second tags, XMP exif `DateTimeOriginal`, XMP photoshop `DateCreated`, and the IPTC pair `DateCreated` with `TimeCreated` (the value the carriers agree on, none when no carrier states it, so no zone or fraction is invented, and a conflict that equals nothing when carriers disagree). A source whose Exif time lacks the offset or fraction that IPTC (with its date) or XMP states for the same time is therefore compared as the one time the host reader and the plan write. A component that only a carrier without its own local time states (an orphan: an Exif offset or sub-second without Exif `DateTimeOriginal`, an IPTC time 2:60 without 2:55) is deliberately no part of that composition, and the host typed snapshot no longer merges it either: a selected capture time of such a source is refused before any write (`TRANSFER_TIME_COMPONENT_UNANCHORED`), as is a destination IPTC time without its date that a write would leave in place. The comparison and the host reader are therefore coherent for anchored components; for orphans the agreement is enforced by that refusal, not by the comparison, and an orphan that an anchored carrier states too is redundant and admitted. An output that drops, changes or adds an offset or fraction, or a source or output whose carriers disagree, is a mismatch, and a source time that the output lists in no carrier is a mismatch. Coverage is by the `E4F1` cases, `NativeTimeCarrier`, the `E4G1` cases and the `E4H1` cases (native refusals of orphan sources and destinations, redundant-orphan and anchored controls, and the host `OrphanTime` rule); the host proof T compares every carrier through the typed snapshot regardless.
- A source fraction into a destination whose only capture time is IPTC is refused before any write (`TIME_SUBSECOND_REQUIRED`). A whole-second captured time (no fraction, or no offset) from an Exif or IPTC source into a destination that has neither an Exif block nor XMP is written into one new XMP carrier and verified (`E4F2` cases); the proof R accepts exactly the typed `XMP_NO_FRACTION` / `XMP_NO_OFFSET` description of an XMP date the plan wrote, and a vanished, unwritten or differing component stays a mismatch.
- JPEG items only. Serial local runs of ExifTool 13.55 against a small private synthetic corpus; this is not an exhaustive or global acceptance.
