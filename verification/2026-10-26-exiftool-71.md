# ExifTool adaptor (allocation 71) completion note

Scope: new route `schemaxis.exiftool/1` (`inventoryPhotos`). Results are item by item; unchecked items say so. Bulk
transcripts are private evidence outside the repository and are not committed. This note is a draft: it is not an
independent acceptance, and the registration/qualification record has not been written (parent gate).

| Item | Result |
| --- | --- |
| registration | Manifest, route, hooks, runtime family 13.55 and `--exiftool`; no framework branch (host test). Qualification not registered. |
| schema | Closed `photos` array (1-16; `id`, `path`, optional `sha256`); generated schemas pending shared generation. |
| semantics | Independent reader refuses duplicate/ambiguous/cyclic/overflowing/mistyped/false-orientation/invalid-date photos, `-00:00` offsets and duplicate source files (path, alias or inode) at `$.photos[i].path` before native. |
| native-mapping | Fixed argv, group-qualified selected tags, `-G1:4`, exact JSON type and number-token comparison; production release 13.55 selected from the official version history (13.59 is development). |
| execution | Two fresh ExifTool processes, runtime hashing before and after, offline verify, live timeout and cancel observed against a genuine ExifTool process after the launcher bound its inputs (not a claim that ExifTool read them), leader exit -15/-9, PID and group gone, no success publication on failure, qualifier safety net must not be needed. |
| discovery | Adaptor-owned search cases; registry-level search not re-run in the shared suites here. |
| guidance | `guidance.json` reviewed; `tools/studio_guidance.py --app exiftool --check` run. |
| help | `docs/exiftool.md`; shared generated reference/Help derived only by the parent after union. |
| examples | Baseline, variant, four invalid inputs and a Calc workflow; Studio baseline and variant templates. |
| tests | Native-free host tests (see FINAL); native qualifier `tools/qualify_exiftool.py` with public-agent loop and public-verifier semantic mutants. Studio browser/UI checks were not run in isolation. |
| qualification | No receipt registered; qualifier evidence is private. |
| maintenance | `upstream.json` records the production-release policy and the absence of a publisher checksum for 13.55. |

Unsupported or unestablished: every tag, format and metadata family outside the selected scope; pixel decoding; capture
truth; any ExifTool version other than 13.55; MPI.
