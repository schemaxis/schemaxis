# whisper.cpp optional caption segmentation target (`maxSegmentLength`)

Route: `schemaxis.whispercpp/1`, `transcribe`. One new optional integer, `maxSegmentLength`
(16 to 200), mapped to the whisper.cpp CLI options `-ml N -sow`. This strengthens the
existing adaptor; `absorbedVersion` stays `1.9.5`, already the latest stable release
(tag `v1.9.5`, commit `d1be6fd`). The upstream build reports `1.9.5-dev` by default
(`WHISPER_BUILD_IS_DEV`); the adaptor already accepts exactly that string and `1.9.5`.

**The option is a native target, not a guarantee.** Words are an unreviewed machine
draft and a person must review every caption against the audio. Nothing here certifies
recognition accuracy, readability, accessibility, confidence or speakers. Cue timing under
`-ml` comes from whisper.cpp's experimental token-level timestamps and is observed, not
certified.

## Upstream semantics (read from the `v1.9.5` source, then observed)

| Item | Finding |
| --- | --- |
| CLI help | `-ml N` "maximum segment length in characters"; `-sow` "split on word rather than on token". `-ml > 0` enables token-level timestamps (documented as experimental). |
| Unit | `whisper_wrap_segment` adds `utf8_len(token)` per token: the count of bytes that are not UTF-8 continuation bytes, i.e. Unicode code points. Not bytes, not grapheme clusters, not display width. The leading space of a word token is counted. |
| Split rule | Before token *i* when `count + token > N`, *i* is not the first token and, with `-sow`, the token starts with a space. |
| Consequences | A word longer than N is never split. Text without space-led tokens (Chinese, Japanese, Thai) is not split and can be far longer than N. Without `-sow` a split can fall inside a multi-byte character, so `-sow` is always passed. |
| Not tested | No multilingual model was run; no multilingual claim is made. The byte/code point finding is from source plus synthetic UTF-8 host tests. |

## Limits and remaining work

- No multilingual, noisy, long-recording, GPU or other-OS claim; no accuracy, confidence or speaker claim.
- Boundary quality is native experimental timing; the host checks only its strict timing policy.
- Human corrections, timing edits and any change to the timed segment format are not part of this change.
