# CFD reader, filter and writer directory

This is a broad CFD-focused selection from the **645 registered ParaView operations** in this checkout. Start with the short lower-case aliases; native `pv...` entries expose a wider range of options. Borderline scientific-flow, particle, AMR and mesh-analysis operations are included deliberately. Astronomy, molecular chemistry, medical imaging and unrelated display helpers are omitted.

Every linked name exists in the current Schemaxis registry. **Registered does not mean natively qualified on your case or installed ParaView release.** Some entries need specialised dataset types, resource inputs, external libraries or plugins. The pinned catalogue comes from ParaView 5.13.3. Use the operation reference and `schemaxis describe NAME` before selecting one.

Return to the [step-by-step CFD guide](cfd-postprocessing.md) or the [complete generated catalogue](generated/paraview-operations.md).

## How to use this directory

1. Find the engineering task below. Prefer a short alias when it covers your needs.
2. Open its link for exact ports, required options, defaults and constraints.
3. Add a node with that `filter` and connect the documented input ports. Native `pv...` options and ports keep their exact case; they are not interchangeable with alias spellings.
4. Writers belong in `scenes[].exports`, with a source `node`, rather than ordinary pipeline nodes. Schemaxis manages filenames and one scheduled state at a time.
5. Check the full input with the authored schema and `plan`; then perform a small native run and inspect the output/readback.

```bash
schemaxis describe foam
schemaxis describe pvGradient
schemaxis describe pvWriteCSVWriter
schemaxis schema --provider paraview --operation pvGradient
```

The operation schema describes only its options object. Associate the **whole ParaView authored schema** with `input.json`; it already includes analytics and expressions.

## Scope of this selection

This directory links **374 distinct operations**. It is a discovery aid, not an exhaustive CFD capability or acceptance claim. The complete catalogue also contains additional generic operations that may be useful for unusual datasets. If a needed operation is absent, inspect the full catalogue and its native requirements before extending the adaptor.

For image rendering, use the guide's **scenes → appearances → images → cameras** sections. Chart views, multi-panel GUI layouts, arbitrary Python filters and general native GUI control are not implied by this list. A reader/filter producing a table or annotation does not itself add a rendered chart or overlay to the supported scene schema.
