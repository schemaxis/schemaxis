DESIGN GUIDE
One document. Several ways to work.
01
Edit a dimension
Change the bend radius in Properties. The JSON updates while its parameter references remain intact. Undo reverses the change.
02
Pick an end
Use Pick inlet, name the selection, then add an extension. This example creates existing profile / cut / fuse operations; general face extrusion still needs native support.
03
Try the source
JSON is editable. Invalid text remains in the editor and blocks operations. YAML shows an export preview; YAML parsing and comment-preserving edits are not implemented here.
04
Review an AI edit
The Assistant demonstrates a fixed suggestion and a real draft update. It sends nothing to an AI service.
All geometry is a procedural illustration, not native evidence. Draft checks are a small local subset, not Schemaxis planning. Reloading resets this prototype; exported files persist.
