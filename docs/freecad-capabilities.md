# FreeCAD capability families

**The strategic completion programme remains open.** This inventory retains all
major stable workflow families; a useful native mechanical-design milestone is
not a claim that FreeCAD needs no further adaptor work. Reviewed against stable
FreeCAD1.1.4 on4 November2026. Native evidence proves the named workflows and
versions, not a measured percentage of the upstream API.

| Stable family | Implemented useful workflow | Verification and remaining work |
| --- | --- | --- |
| Sketch geometry/constraints | Rectangle/circle shortcuts, fully constrained capsule slots, closed polygons; named lines/circles/arcs and construction geometry; typed geometric/dimensional relations | Native solve, direct constraint/geometry readback, independent host residuals, XML persistence. Ellipses/conics/splines, external geometry, symmetry/advanced relations and arbitrary constraint expressions remain open. |
| Frames, datums and references | Independent orthonormal frames, XY/XZ/YZ shortcuts, Body-owned arbitrary datum axes; checked directional planar-face attachments with outermost/innermost and projected-origin/centroid intent | Exact cardinality and semantic inventories; native FlatFace links, dimension propagation and fresh reopening. General curved/rotated face support, richer datum planes, topology repair and general subelement references remain open. |
| PartDesign histories | Independent multiple Bodies; explicit current-tip composition; subsequent Pads, finite/through Pockets, revolutions/grooves, native unthreaded Hole with grid/pitch-circle locations, drill tips and head recesses; uniform native Skin shells with directional openings/inward-outward/sharp-rounded offsets; additive/subtractive sweeps with dimensioned bend paths, orientation guides/world binormals and changing sections; native Body fillet/equal-distance chamfer, linear/polar/mirror patterns, additive/subtractive lofts | Analytic feature-family cases and driven enclosure/cavity/four bosses/four bores/slotted lid; native edit-save-fresh-reopen-second-edit. Threaded/tapered/standards-table Hole modes, arbitrary 3D/spline sweep paths, variable thickness/general surface offsets, draft, helix, variable dress-ups, multitransforms and further extent modes remain open. |
| Part solids/booleans | Primitives, profile extrusion/revolution/loft, union/difference/intersection, finishing and geometric edge selection | Existing and new handoff checks. General BRep construction, splitting, offsets, curves/surfaces, multi-solid publications and shape healing remain open. |
| Draft / 2D drafting | Editable straight-edged Wire outlines compose native Part extrusion and booleans; see [polygon profiles](freecad-draft-profiles.md) | Development qualification binds full saved geometry and coherent trusted native save states. Curves, dimensions/text, arrays/clones/transforms, snapping workflows, Body seeding and sourced-history copying remain missing; this is not broad Draft completion. |
| Parameters, measurements, studies | Affine native length drivers including slot span/radius, named geometry facts, finite batches and bounded scalar study on its declared subset | Enclosure wall/floor/height/boss dimensions preserve native links. General dimensional expression ASTs, angular drivers, sketch coordinate drivers, PartDesign scalar studies and reverse synchronisation remain open. |
| Import/export and editable documents | Checked single-solid STEP import with unit/orientation/placement/facts; FCStd editable supported histories; independently checked STEP/STL geometry handoffs | Retained sources, saved XML and fresh native reopening. General imported FCStd editing, STEP assemblies, arbitrary formats, imported-history recovery and broad repair remain open. |
| Assemblies and mechanisms | Fixed assemblies, shared complete multi-Body source histories, selected-Body mounts and native joints | Fresh trusted regeneration binds maps/shadows/payloads and indexed geometry/consumers; enclosure shared-source native edits/reopen, standalone source removal and loft/pattern/datum/dress-up cases pass. Moving joints, mechanism simulation, mixed sources, subassemblies and interference remain open. |
| TechDraw and drawings | Native editable A4/A3 sheet with standard orthographic/isometric views, geometric linear/radial dimensions, annotations/title/revision/notes and SVG/PDF | Native measured projections, independent rendered enclosure sheet, edit/reopen/tamper/workflow/source-removal checks. Sections/details, hatching, GD&T, multi-page sheets, BOMs, DXF and associative source updates remain open. |
| Manufacturing/CAM | Geometric STEP/STL handoffs provide upstream design artifacts | Native setups, stock/tools/fixtures, operations, path generation, postprocessing, collision/material-removal verification and revision handoff remain important open work. |
| FEM and simulation | Checked CAD → editable native linear-static solid material/mesh/support/traction/CalculiX/results; independent deck/fields, equilibrium and energy | Analytic T4/T10, pressure/displacement controls, enclosure/refinement and native edit/second-solve/fresh-reopen. Contact, nonlinear, multimaterial, modal, thermal, transient and beam/shell workflows remain open; see [analysis guide](freecad-analysis.md). CFD follows the distribution boundary. |
| BIM and specialist bundled workflows | No broad authoring contract | BIM, Draft architecture, general surfacing and other stable bundled families remain explicit programme gaps. Third-party add-ons need separate scope and provenance. |

All part lengths use millimetres. Each PartDesign solid feature must leave one
valid positive-volume solid; one selected final tip is exported while the native
document retains all authored Bodies. The [history guide](freecad-histories.md)
explains the mechanical intent and limits. The [strategic programme contract](adaptor-strategic-completion.md) defines acceptance across families. No absent
stable family is excluded merely because implementation is difficult.

Sweep workflows and persistent centroid materialisation are described in the [sweep guide](freecad-sweeps.md); full-family completion remains open.
