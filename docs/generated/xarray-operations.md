## reduceProfile

Reduce a captured classic NetCDF measurement cube to a coordinate-labelled profile. The route decodes the file with a bounded standard-library reader, asserts dimension names, order, units and the missing sentinel, selects inclusive numeric coordinate ranges, averages the other named dimensions with an explicit missing policy, and publishes a smaller NetCDF profile, a numeric CSV with valid and missing counts, and a summary with source, axis and selection hashes. Isolated xarray does the work and an independent verifier checks every coordinate, value, unit and count.

Common mistakes and assumptions:

- Dimensions must be declared in the exact storage order as a deliberate layout assertion; a permuted order is refused, never silently reinterpreted.
- The mean is unweighted over selected cells: it is not area, volume or time weighted, and no uncertainty is claimed.
- Strongly cancelling means (relative error bound above 1e-9) are refused as ill-conditioned; a profile of all-missing points is refused, never zero.
- Only classic NetCDF CDF-1 with double data, a small attribute allowlist and strictly increasing coordinates; other information is refused, not dropped.
- To plot the profile, connect Gnuplot with source {"$artifact": "<id>", "index": 1} (profile.csv). Declare its four columns and units yourself: the CSV has none, nothing is converted, and a propagate profile with an empty mean cell is refused by Gnuplot's CSV validation.

Native binding: `xarray.open_dataset(engine="scipy"), Dataset/DataArray.sel(slice), DataArray.where, DataArray.mean(dim, skipna), Dataset.to_netcdf(format="NETCDF3_CLASSIC")`. Output kind: `["file","table","text"]`.

Inputs: none.
