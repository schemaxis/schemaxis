## bundle

Package the individual files you choose (captions, transcripts, audio, reports, images) under safe flat names into one portable ZIP for handoff. The host captures every file, writes a manifest.json inventory of names, sizes and SHA-256 digests, asks the trusted Info-ZIP zip to store the members, and then reads the whole archive back with an independent strict reader so that every archive byte is compared with the captured bytes. Choose it to deliver a set of finished publication files together; it does not preserve or restore a whole case, compress, sanitise or authenticate anything.

Common mistakes and assumptions:

- Only the files you list are packaged: run directories, receipts, logs and other evidence are never added automatically, and leaving them out is not privacy sanitisation. For whole-case preservation use the core storage preservation action.
- Members are stored without compression, so the ZIP is not smaller than its contents and no compression ratio is claimed. Contents are opaque: no media, accessibility, security or privacy check is made.
- manifest.json is an unsigned inventory, not a signature; a coherent rewrite of the archive and its retained captures verifies as a new archive.

Native binding: `zip -v; zip -X -0 -q bundle.zip <member names in authored order> manifest.json (Info-ZIP Zip 3.0, stored members only); host writes manifest.json and reads bundle.zip back`. Output kind: `["file","text"]`.

Inputs: none.

| Option | Meaning | Type / constraints | Default |
| --- | --- | --- | --- |
| `files` | One to sixteen files to package, in the order they will appear in the archive (manifest.json is always added last). Each entry names the member and its source file. A verified file, text or image artifact from an earlier workflow step can be bound to an entry source. | `{"type":"array","minItems":1,"maxItems":16,"items":{"type":"object","properties":{"name":{"type":"string","minLength":1,"maxLength":53,"required":true},"source":{"type":"string","minLength":1,"maxLength":4096,"required":true}}}}` | **required** |
