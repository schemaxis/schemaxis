## routeStations

Place stations every N metres of true WGS84 geodesic distance along an ordered route of longitude/latitude waypoints, continuously across turning points. Isolated pyproj computes leg lengths, azimuths and station positions; an independent standard-library verifier re-evaluates every leg, station, consecutive step and requested endpoint gap and the host decides any requirements. Publishes labelled station and leg tables, station and route GeoJSON, a summary and a verification record.

Common mistakes and assumptions:

- Numerical agreement only: no survey, datum, measured-position, physical or regulatory accuracy is claimed.
- GeoJSON segments between published vertices are straight in longitude/latitude, not geodesic.
- Unmet or indeterminate requirements are retained evidence, not accepted deliverables.

Native binding: `pyproj.Geod(ellps='WGS84').inv per leg (and requested endpoint gap); Geod.fwd per fixed station`. Output kind: `["table","geospatialVector","text"]`.

Inputs: none.

| Option | Meaning | Type / constraints | Default |
| --- | --- | --- | --- |
| `source` | Required absolute path to a regular ASCII .csv of at most 1 MiB with 2-500 waypoints in route order. The header is exactly lon_deg,lat_deg or name,lon_deg,lat_deg; cells are plain decimal degrees. The bytes are captured for standalone verification, the arithmetic uses their parsed binary64 values, and changed or removed source bytes invalidate reuse. | `{"type":"string","minLength":1,"maxLength":4096}` | **required** |
| `ellipsoid` | Required and must be WGS84 (a = 6378137 m, 1/f = 298.257223563). A sphere or any other ellipsoid is refused, never substituted. | `{"type":"enum","values":["WGS84"]}` | **required** |
| `coordinateOrder` | Required and must be lonLat: longitude first, then latitude, in decimal degrees. Stating it prevents silent axis swaps. | `{"type":"enum","values":["lonLat"]}` | **required** |
| `spacing_m` | Required station spacing in metres of geodesic distance, 0.1 m to 1000 km. Stations lie at chainage k x spacing_m measured from the start, continuously across waypoints; at most 10000 rows may be published. | `{"type":"number","minimum":0.1,"maximum":1000000.0}` | **required** |
| `closed` | Optional, default false. When true a closing leg from the last waypoint back to the first is added and the final row repeats waypoint 1; do not repeat the first waypoint in the CSV. | `{"type":"boolean"}` | `false` |
| `requirements` | Optional requirements decided by the host against a numerical band: met, unmet or indeterminate. Unmet or indeterminate requirements keep all evidence but fail the run as an accepted deliverable and block downstream reuse. | `{"type":"object","properties":{"totalLength_m":{"type":"object","properties":{"minimum":{"type":"number","minimum":0,"maximum":20000000.0},"maximum":{"type":"number","minimum":0,"maximum":20000000.0}}},"endpointGap_m":{"type":"object","properties":{"maximum":{"type":"number","minimum":0,"maximum":5000000.0,"required":true}}}}}` | omitted |
