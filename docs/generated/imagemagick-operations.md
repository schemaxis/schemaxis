## raster

Run the raster preparation recipe: crop, integer magnification, quarter turns, explicit alpha and optional indexed sheet.

Common mistakes and assumptions:

- Encoded sRGB sample arithmetic; no colour management, smoothing, scripts or visual text labels.
- Only bounded RGB/RGBA8 PNG with exact independent pixel qualification.

Native binding: `magick: -crop +repage -sample -rotate -alpha remove; -compose Copy -composite; PNG coder`. Output kind: `["image","text"]`.

Inputs: none.
