## assemble

Build a new PDF from selected pages of one to four named PDFs. Choose the pages in the order you want them, repeat a page by listing it again, and turn any listed page clockwise by a quarter turn. Each PDF is captured before execution; after assembly the captured sources and the published PDF are reopened with QPDF and MuPDF and every output page must match its source page exactly in a 36 dpi raster, its text and its geometry. This is bounded page assembly, not a sanitiser or editor: document-level data such as bookmarks, links on selected pages, metadata and page labels is discarded or refused, and sources with forms, signatures, layers, tagged structure or encryption are refused.

Common mistakes and assumptions:

- Page numbers are the one-based physical position in the PDF, not the printed page label.
- Rotation is added to the page's own rotation; it does not set an absolute orientation.
- Bookmarks, named destinations, document information and page labels are not carried into the output.
- Pages with link or other annotations or a transparency group, and PDFs with forms or layers, are refused rather than altered.
- A PDF that QPDF has to repair is refused; supply an intact copy.

Native binding: `qpdf --empty --pages FILE PAGE ... -- --rotate=+N:K --remove-page-labels --deterministic-id; MuPDF PDFDocument.findPage/PDFObject.put/getInheritable, PDFPage.getBounds/toPixmap/toStructuredText`. Output kind: `["pdf","text"]`.

Inputs: none.
