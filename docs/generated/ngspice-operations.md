## acSweep

Characterise bounded ideal linear RLC networks across linear, decade or octave frequencies: native node voltages, optional native source-current/KCL checks, derived input impedance and passive branch complex power. Declare peak/RMS phasor convention and sampled gain, relative phase, current, power or loading requirements. Results retain verified CSV, circuit summary and inspectable netlist. Use for filters, source loading, resonance and resistor heating; no nonlinear or general transient claim.

Common mistakes and assumptions:

- For logarithmic spacing points is nominal samples per decade/octave, not total output count; actual count must fit3–512.
- Declare peak or rms amplitude convention before interpreting power; currents are a to b and input current is -i(vdrive). Branch current is derived, whereas input current is native observed.
- Phase requirements use principal relative Vprobe/Vsource angle and refuse zero response. A bound never wraps and solver tolerance does not relax user acceptance.
- Every frequency must have a nonsingular, conditioned network; no ideal-inductor/source loops, mutual coupling, nonlinear models or continuous-envelope guarantee.

Native binding: `ngspice ac lin/dec/oct`. Output kind: `["table"]`.

## dcSweep

Steps one ideal grounded voltage source through evenly spaced DC values and reports the steady node voltages of a resistor network (capacitors act as open circuits). Outputs are results.csv (source voltage, then one column per probe in volts), circuit-summary.json and the generated netlist circuit.cir; every native value is checked against an independent nodal solution. Choose it for dividers, bridges and other resistive networks; use acSweep for frequency response and rcStep for a charging curve.

Common mistakes and assumptions:

- start and stop are source volts and stop must exceed start; points includes both endpoints.
- Every node needs a path through resistors to ground or the source; a node reached only through capacitors is rejected as floating.
- Only ideal resistors and capacitors; semiconductors, models, subcircuits and imported netlists are not accepted.

Native binding: `ngspice dc`. Output kind: `["table"]`.

## rcStep

Simulates an initially uncharged series resistor feeding a grounded capacitor when a constant voltage is switched on at t = 0, and reports the source and capacitor node voltages at evenly spaced times. Native transient values are resampled and checked against V x (1 - exp(-t/RC)). Outputs match the other analyses (results.csv with time in seconds, summary and netlist). Choose it for RC charging and settling-time checks only.

Common mistakes and assumptions:

- The circuit must be exactly source - resistor - response node - capacitor - ground; any other topology fails with UNSUPPORTED_CIRCUIT.
- stop (seconds) must lie between 0.01 and 20 time constants R x C; the default 0.005 s suits only RC values near 0.25 to 500 ms.
- The default probe is "out"; name the capacitor node "out" or list the actual node in probes.

Native binding: `ngspice tran/linearize`. Output kind: `["table"]`.
