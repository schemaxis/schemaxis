## validate

Check one finished EPUB publication with the official W3C EPUBCheck tool before it is handed over. The host first checks that the file is a safe, bounded ZIP, then the trusted checker examines the captured bytes against the EPUB standard. The result is accepted only when EPUBCheck reports no fatal, error or warning messages; the JSON assessment and a short summary are then published, and a fresh second check of the held bytes must agree. Choose it as an independent standards check after a conversion (for example a Pandoc EPUB); it does not edit, repair, render or certify the book.

Common mistakes and assumptions:

- A rejected publication publishes nothing: the run fails with EPUBCHECK_REJECTED and the findings stay in rejected-assessment.json in the run directory. Warnings reject too, because the policy is zero fatal, error and warning messages.
- Only the default EPUB profile runs; you cannot choose dictionary, EDUPUB, index or preview profiles, downgrade a message severity or add checker flags.
- Zero findings is a scoped result from one EPUBCheck release, not proof of correct rendering on a reading system, accessibility or legal compliance.
- Verification needs the same trusted launcher (SCHEMAXIS_EPUBCHECK, a stored epubcheck location, or --epubcheck for run); it can never succeed without it.

Native binding: `epubcheck captured.epub --json assessment.json --failonwarnings --quiet --maxOfEachMessage unlimited --locale en (official EPUBCheck 5.4.0 distribution through a configured fixed launcher); no profile, mode, custom-message or severity options`. Output kind: `["file","text"]`.

Inputs: none.

| Option | Meaning | Type / constraints | Default |
| --- | --- | --- | --- |
| `source` | Choose one absolute local .epub file of at most 32 MiB, 2000 members and 64 MiB uncompressed. A verified file artifact from an earlier step, such as the EPUB published by a Pandoc report (artifact index 3 of that run), can be bound here. Its bytes are captured before checking and decide scheduler reuse. | `{"type":"string","minLength":1,"maxLength":4096}` | **required** |
