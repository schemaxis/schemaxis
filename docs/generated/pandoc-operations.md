## report

Publish an ordered report with a visible title, sections, plain paragraphs, rectangular text tables and captured PNG figures as standalone HTML and editable Word DOCX. Use it for small measured-result reports. Trusted JSON AST, sandboxed writers, independent HTML/OOXML inspection and fresh DOCX native readback retain actual declared content. Default typography and pagination are not an exact layout or accessibility contract.

Common mistakes and assumptions:

- Replace each image placeholder with an absolute regular plain RGB/RGBA PNG path.
- Begin headings at level 1 and avoid increasing by more than 1.
- Every table row must have one text cell per column; numeric values must be written as strings.
- No authored markup, templates, filters, scripts, rich text or arbitrary input-document conversion.

Native binding: `Pandoc JSON AST: Header / Para / Table / Image; html5 / docx writers; docx reader`. Output kind: `["text","file"]`.

Inputs: none.
