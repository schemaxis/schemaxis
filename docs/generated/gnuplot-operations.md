## plot

Create a scientific plot from captured numeric CSV columns, explicit units, named series and linear/log10 axis ranges. Publish SVG, PNG, source capture and an editable trusted script. Optional symmetric y uncertainty draws measured intervals. Independent SVG coordinate and decoded PNG pixel checks compare actual native output with captured values. Fixed styles and connected samples only; no arbitrary commands, expressions, fits or unit conversion.

Common mistakes and assumptions:

- Replace the absolute CSV placeholder and match the exact declared header order.
- Choose increasing x values, explicit inclusive ranges and matching column/axis units.
- For log10, every sample and uncertainty endpoint must be positive.
- Overlapping series may obscure one another and fail independent pixel identification; choose distinguishable data/colours.

Native binding: `plot using x:y[:dy] with linespoints/yerrorlines; set xrange/yrange/logscale; svg/png terminals`. Output kind: `["image","text","file"]`.

Inputs: none.
