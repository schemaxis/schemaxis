## plot

Create a scientific plot from captured numeric CSV columns, explicit units, named series and linear/log10 axis ranges. Publish SVG, PNG, source capture and an editable trusted script. Optional symmetric y uncertainty draws measured intervals. Independent SVG coordinate and decoded PNG pixel checks compare actual native output with captured values. Fixed styles and connected samples only; no arbitrary commands, expressions, fits or unit conversion. A series may instead declare bounds {lower, upper}: three numeric columns (central, lower, upper) in the y-axis unit draw a shaded piecewise-linear envelope behind the central curve. The envelope connects ASSERTED bounds supplied by the data; it computes no quantile, distribution, confidence level, simultaneous coverage, reliability or model validity, and the straight interpolation between rows is display only.

Common mistakes and assumptions:

- Replace the absolute CSV placeholder and match the exact declared header order.
- Choose increasing x values, explicit inclusive ranges and matching column/axis units.
- For log10, every sample and uncertainty endpoint must be positive.
- Overlapping series may obscure one another and fail independent pixel identification; choose distinguishable data/colours.
- Use bounds for a lower/upper range that is not symmetric about the central value; use error for a symmetric absolute interval and neither for plain points. A series cannot declare both.
- An envelope needs every row finite with lower < central-or-equal <= upper, strictly increasing x, linear axes, a single series and at least 24 pixels of height at each row, with an observable interior and exterior away from the tick-bearing plot borders (otherwise PLOT_BAND_UNVERIFIABLE before Gnuplot starts); nothing is clipped, sorted or imputed, so fix the data or the axis ranges.

Native binding: `plot using x:y[:dy] with linespoints/yerrorlines, or x:lower:upper with filledcurves plus x:y with linespoints; set xrange/yrange/logscale; set style fill transparent solid 0.2 noborder; svg/png terminals`. Output kind: `["image","text","file"]`.
