| `threads` | One or two native compression workers. This is distinct from single-thread I/O; ordinary one-worker mode can still use asynchronous I/O. | `{"type":"integer","minimum":1,"maximum":2}` | `1` |

| `dictionary` | Select exact trained dictionary bytes or raw history bytes using dictionaryMode. A numeric dictionary ID is not a cryptographic identity. In a workflow, a pinned adopted file or an explicitly selected directory-snapshot member can supply these bytes; changing its captured content is refused. | `{"type":"string","minLength":1,"maxLength":4096}` | omitted |
| `dictionaryMode` | Trained dictionaries include the Zstandard magic header and numeric identifier. Raw dictionaries are nonempty history bytes without that header and use dictionary ID zero. Both require exact retained bytes for restoration. | `{"type":"enum","values":["trained","raw"]}` | `"trained"` |
| `contentSize` | Automatic includes a known file size and omits an unknown stream size. Omit suppresses the frame size. Require needs an exact pledgedBytes value for a standard-input stream. Actual decoded output remains bounded in every mode. | `{"type":"enum","values":["automatic","omit","require"]}` | `"automatic"` |
| `pledgedBytes` | Exact total source bytes for one standard-input frame. The captured byte count must match before native execution. A pledge cannot be combined with chunking or an approximate size hint. | `{"type":"integer","minimum":0,"maximum":67108864}` | omitted |
| `sizeHintBytes` | Hint used to select compression parameters for a standard-input stream. It does not assert the actual size or remove decoded-output limits. Use pledgedBytes when an exact frame size is required. | `{"type":"integer","minimum":1,"maximum":67108864}` | omitted |
| `targetBlockBytes` | Zero uses the native default. A positive value asks for an approximate compressed block size, 64–131072 bytes. It is a compression target rather than an exact block-size or random-access guarantee. | `{"type":"integer","minimum":0,"maximum":131072}` | `0` |
