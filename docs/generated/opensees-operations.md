## trussStatic

Assess linear elastic planar truss networks: signed axial force and stress, deflection, support reactions and named serviceability limits.

Common mistakes and assumptions:

- Nodes carry geometry and independent Cartesian restraints; members carry E and area, allowing redundant and mixed-stiffness structures.
- Host direct stiffness checks stability before execution and independently verifies all native displacements, axial responses and reactions.
- Fresh-process reconstruction reads the retained model; this is not a native database persistence claim.

Native binding: `openseespy.opensees: Elastic + Truss + Static`. Output kind: `["table","text"]`.

Inputs: none.
