## editTimeline

Cuts, reorders and repeats frame ranges from local video files into one Shotcut (MLT) timeline. It publishes a lossless FFV1 video.mkv, the editable project.mlt (which needs its captured media files beside it) and project-bundle.zip containing both. Every rendered frame is compared with the selected source frames, and the project is reloaded and re-rendered to confirm it reproduces the same video. Choose it for frame-exact edits of existing videos; use FFmpeg encodeFrames to make a video from still images.

Common mistakes and assumptions:

- Sources must be silent, progressive, square-pixel videos at exactly the timeline fps, width and height; there is no resizing or rate conversion.
- startFrame is zero-based and frameCount is a number of frames, not seconds.
- Audio, gaps, transitions, filters and multiple tracks are not supported.
- Keep project.mlt together with its asset-XX.media files, or use project-bundle.zip, when moving the project.

Native binding: `Shotcut MLT XML playlist`. Output kind: `["video","videoProject","videoProjectBundle"]`.

Inputs: none.
