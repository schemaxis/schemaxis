## transcribe

Transcribe one pinned local PCM16 mono 16000 Hz recording with one pinned local ggml model into millisecond segments, plain text, SRT and WebVTT. Optionally add a caption review report of per-cue duration and text-density flags, and optionally ask whisper.cpp to split cues toward a target length at word boundaries. The run is offline and serial; structure and hashes are verified, but recognition accuracy is not, so a person must review the result.

Common mistakes and assumptions:

- The model and audio SHA-256 values pin exact bytes; changing either file requires a deliberate new pin.
- A well-formed result can still contain wrong, missing or invented words. Review captions against the audio before use.
- Silence or no detected speech publishes nothing and fails with TRANSCRIPT_EMPTY.
- A caption review report is optional editorial triage with fixed thresholds of our own, not a standard or certification; no flags does not mean the captions are good.
- maxSegmentLength is a native target, not a guarantee: a word longer than the target, or text in a script written without spaces, stays in one longer cue, and the cue boundary times come from experimental native token timestamps. Over-target cues are published and counted, not refused.

Native binding: `whisper-cli -m MODEL -f audio.wav -l LANGUAGE -t 1 -p 1 -ng -oj -osrt [-ml MAXSEGMENTLENGTH -sow] -of native`. Output kind: `["file","text"]`.

Inputs: none.
