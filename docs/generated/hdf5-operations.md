## extractData

Read slices, strided block hyperslabs, point lists, compound fields or the rows meeting typed conditions of datasets in an existing HDF5 file into CSV tables (with dimension-scale coordinates and units in the header), NPY arrays or JSON for downstream tools.

Common mistakes and assumptions:

- Selections are checked against the dataset shape; expected values are selected on the host from the independent h5dump reading.
- access.memoryBytes streams each extract in bounded axis-0 blocks; parallel reads blocks on MPI ranks (local workstation qualification).
- CSV rows follow axis 0; remaining axes are flattened in C order into columns.
- where keeps axis-0 rows meeting typed conditions; h5py and the independent reading must choose the same rows.
- A chunk index is checked by decoding every listed chunk from the file bytes on the host (gzip, shuffle, Fletcher-32).

Native binding: `Dataset[selection] (slices, MultiBlockSlice hyperslabs, point lists, field names) with dimension-scale coordinates`. Output kind: `["table","file","text"]`.
