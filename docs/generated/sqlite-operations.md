## summarise

Join typed tables through a declared foreign key, optionally filter integers, then group and count/sum exact integer amounts. Choose this for reproducible relational reports and a fresh checked database. Null join keys are omitted, null values are ignored by SUM, and an all-null group has a null total.

Common mistakes and assumptions:

- Use exact JSON integers, explicit nullability and primary/foreign keys; do not pass SQL or a pre-existing database.

Native binding: `CREATE TABLE STRICT; INSERT; SELECT INNER JOIN WHERE GROUP BY COUNT SUM ORDER BY`. Output kind: `["file","text"]`.
